# 让 Agent 接入并校对一首谱

任选能读本地文件、查看图片并执行命令的 Agent。先按 [Windows 安装说明](../README.md#windows-安装)完成环境配置。需要查询或编辑 JPword 工程时，可追加 [本地 stdio MCP](jpword-mcp.md)。提供五线谱 PDF、任务目录、乐器、首调或固定调约定。只有严格复刻原谱分行或精修符号时，才需要额外提供同风格的 JPword 参考模板。

## 可复用的任务指令

> 请使用本项目把我指定的单声部乐器分谱转为纯简谱印刷稿。运行 `prepare`；如果我提供了识谱稿，作为草稿继续。打开实际原谱或预览页，与 MusicXML 逐小节比对。确认音高、八度、时值、调拍及演奏记号后保存 `reviewed.musicxml` 和 `review-notes.md`。运行 `handoff` 与 `render`，打开两份生成的 PDF 逐页复验。在 `print-review.md` 写明检查结果，然后运行 `finalize`。如需 JPword 精修，用可用的桌面操作工具打开当前工程、调整并实际导出 PDF。交付纯简谱、线简对照稿及校对记录。

## 核对原谱

1. 确认分谱身份、页码、每行小节数、谱号、调号、拍号、移调及换乐器的位置。
2. 逐小节读原谱，核对音高、八度、临时升降还原、时值、休止、同音延音、连奏和连音组。遇到弱起、反复、房子、复合休止或扫描模糊，按原谱确认，留下页码、小节和疑点。
3. 区分时值附点、八度点和跳音点。演奏版可依乐团习惯将跳音写为实心倒三角 ▼。校对 tr、倚音、滑音、力度、速度、换气、延长和文字，逐项确认所附着的音。音义明确时先修 MusicXML，再检查印刷稿中符号是否保留。
4. 将每次修改的原因和未确定事项写入 `review-notes.md`。对照稿和纯简谱生成后，检查原谱行号、页边距、谱行密度、符号重叠、跨页及整小节休止。若走 JPword 路径，复查实际导出的 PDF。

Agent 能读取数据并辅助核查。对排练或正式印刷使用的稿件，以逐页核对过的 PDF 为准。
