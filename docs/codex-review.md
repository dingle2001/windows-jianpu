# 把任务交给 Codex

在 Codex 中打开项目目录，给出原始五线谱 PDF、任务目录、目标乐器及记谱规则。使用下方任务说明。若要严格复制原谱的每行小节数，请同时提供已完成的 JPword 参考模板。

> 请使用本项目把这个单声部乐器分谱转为可排练的纯简谱。我会提供原谱 PDF 路径、存放成果的目录、是否采用首调以及演奏乐器。你需要实际运行识谱；若已有初稿可作为输入。逐页打开 PDF 或渲染页图，在逐小节核对后修订 MusicXML，再拿线简对照和纯简谱排版稿复验。JPword 需要精修时，用 Computer Use 打开实际工程、修改并导出，最终交付纯简谱 PDF 和校对记录。

### 审阅原谱与识谱稿

1. 确认分谱身份、原稿页码和每行小节数。明确谱号、调号、拍号、首调或固定调、移调约定和换乐器的位置。
2. 逐小节核对音高、八度、临时升降还原、时值、休止、跨小节同音延音、连奏和多连音。弱起、反复、选段、复合休止按原谱阅读顺序核对。
3. 乐谱上的附点靠音符右侧，跳音点在音符上方或下方。需要按乐团习惯转换时，在简谱中用实心倒三角 ▼ 表示 staccato，保留时值附点和八度点。核对 tr、倚音、滑音、力度、速度、换气、延长和文字标记，记录符号所属的小节与音符。语义明确时先修 MusicXML，排版丢失时再在 JPword 补记并复核。
4. 以 `reviewed.musicxml` 保存校订版，用 `review-notes.md` 记录原谱页、行、小节、识谱差异、修改及待确认项。手写扫描模糊、节拍或记谱法不明时，保留具体证据并询问，不猜音。

### 复验导出

- 对照稿中核对每页每行对应关系。纯简谱检查页面边距、可读字号、连线和装饰音是否重叠、换页是否打断乐句。按模板同排时对照每行的小节数，并用 JPword 微调。
- 复核标题、调拍、速度、力度、节奏及实际显示的符号。不要凭 MusicXML 中已有数据推断 PDF 也有。PDF 中的演奏符号实际缺失时，修稿后重验。
- JPword 路径用 Computer Use 进入打印或导出菜单并检查目标文件，避免把线简对照作为纯简谱交付。
- 在 `print-review.md` 写明实际检查了哪些页、哪些标记、还有什么疑点。完成后运行 `finalize`，向用户报告所用的记谱规则、版本、实际通过的检查及未验证范围。
